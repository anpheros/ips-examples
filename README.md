# International Patient Summary (IPS) examples in FHIR R4

**30 HL7 FHIR International Patient Summary documents** (IPS, `hl7.fhir.uv.ips` 1.1.0), one per synthetic patient:
document Bundles with Composition, Patient, allergies, medications, problems, immunizations, lab results and vital
signs, plus the narrative for each section. Useful for testing IPS viewers, cross-border health record exchange
(EHDS), patient summary import and FHIR document parsing.

They were generated by the Anpheros FHIR API (`GET /fhir/R4/Patient/{id}/$summary`) from the synthetic patients in
[anpheros/fhir-synthetic-patients](https://github.com/anpheros/fhir-synthetic-patients). No real person is behind them.

| Path | What it is |
|---|---|
| [`summaries/`](summaries) | one IPS document Bundle per patient, e.g. [`04-andrei-popescu.json`](summaries/04-andrei-popescu.json) |
| [`manifest.json`](manifest.json) | the list of documents and the IG version |

## What each document declares

- `meta.profile` on the Bundle (`Bundle-uv-ips`), Composition, Patient, AllergyIntolerance, MedicationStatement,
  Condition and laboratory Observations (their `-uv-ips` profiles); vital signs use the FHIR vital signs profile.
- The required sections (Allergies, Medications, Problems) are always present; when nothing is recorded they carry an
  explicit "no information" entry instead of being left out.
- `Composition.author` is the platform (a Device) and `custodian` an Organization, both inside the Bundle.
- Narrative: a document-level summary and a table per section, in English (`lang` / `xml:lang`).

## Validation

The `$summary` endpoint that produced these files was validated with the official HL7 validator
(`validator_cli.jar` 6.10.4, `hl7.fhir.uv.ips#1.1.0`, FHIR 4.0.1, tx.fhir.org) on 20–22 September 2026: **0 errors**
on documents with data in every section, with nothing recorded, with "no known allergies" and with immunizations.
Check any file yourself:

```bash
java -jar validator_cli.jar summaries/04-andrei-popescu.json -version 4.0.1 -ig hl7.fhir.uv.ips#1.1.0
```

## Quick start in 2 minutes: generate your own

1. [Get a free sandbox key](https://platform.anpheros.com/dashboard/?utm_source=github&utm_medium=readme&utm_content=ips-examples) (`sk_test_…`).
2. Pick a patient and ask for the summary:

   ```bash
   PID=$(curl -s -H "Authorization: Bearer $ANPHEROS_KEY" "https://platform.anpheros.com/fhir/R4/Patient?_count=1" | jq -r '.entry[0].resource.id')
   curl -H "Authorization: Bearer $ANPHEROS_KEY" "https://platform.anpheros.com/fhir/R4/Patient/$PID/\$summary" > ips.json
   ```

`?lang=ro` returns the narrative in Romanian; other languages fall back to English.
